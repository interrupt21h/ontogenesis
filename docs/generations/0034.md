# Generation 0034 — Four-dimensional component genealogy

*Status: Verified numerical post-processing and independently rendered cinematic; this is **not** a new integrator or an additional independently initialized simulation.*

[← Experiment atlas](../EXPERIMENTS.md) · [Visual gallery](../VISUAL_GALLERY.md) · [Interactive Lineage Observatory](https://interrupt21h.github.io/ontogenesis/lineage-observatory.html)

## The idea

The G0033 experiment retained native 16⁴ numerical fields at eleven discrete integration steps. G0034 asks a different question: **what happens to the geometry of the thresholded concentration regions themselves?** A region can connect around the periodic boundary, disappear below threshold, or overlap several regions in the next stored snapshot. Looking at these relationships provides a new visualization grammar—branching and merging *graph lines*—without fabricating populations, steps or organism identities.

## Inputs and provenance

The source is the successfully completed [G0033 eight-seed pilot, run 45437009050](https://github.com/interrupt21h/ontogenesis/actions/runs/45437009050). Only the real native float32 four-dimensional fields for seeds **42 and 73** are used for this bounded first genealogy pilot. Two previously prescribed treatment arms are retained: `near_transition` (V loss multiplier 0.97; no niche) and `separated_070` (V loss multiplier 0.97; static niche strength 0.70). All 11 stored steps are used: **0, 24, 48, …, 240**. The species readouts are **V-only** and **W-only** sites under the **strict activity threshold > 0.10**.

At each recorded time, a site belongs to one exclusive mask only if its own species is active and the other is not. Same-site co-activity is deliberately excluded from these masks. The record carries the SHA-256 identity of each original compressed 4D field archive; CI compares those hashes against the independently published G0033 numerical report before any analysis or rendering.

## Four-dimensional connected components

Connected components use **face connectivity along all four spatial coordinates**, including periodic connections across opposite boundaries. A 4D lattice site therefore has eight directed nearest-neighbor relationships, four positive and four negative, with each undirected connection counted once.

The implementation first labels the ordinary interior 4D face connectivity using `scipy.ndimage.label` and a connectivity-one structuring element. It then unions the components connected across each axis's periodic wraparound plane, and compacts labels deterministically. Diagonally touching sites are *not* connected. Every active site is accounted for in one labeled component.

- The *component count* and *largest component size* include **all** thresholded regions, regardless of rendering cutoff.
- For readability, visual nodes are limited to the largest 24 components of at least 16 sites per snapshot.
- Each visual node is proportional to its recorded component size. No object shapes are extrapolated or smoothed from video frames.

## Measured overlap genealogy

For two consecutive stored 4D masks, an edge `A → B` exists if the components share at least one identical lattice coordinate at those two recorded steps. Its weight is the **exact number of intersecting sites**.

The complete overlap graph—not just the illustrated nodes—defines the following threshold events:

| Readout | Precise computational meaning |
|:--|:--|
| New component | A component in the newer snapshot has no incoming overlap edge |
| Disappeared component | A component in the previous snapshot has no outgoing overlap edge |
| Observed split | A component in the previous snapshot overlaps more than one newer component |
| Observed merge | A component in the newer snapshot overlaps more than one previous component |
| Persistent overlap | At least one edge connects recorded components through successive samples |

A node that no longer overlaps at the next sampled time is not necessarily physically destroyed: it may have moved, shrunk, briefly crossed the threshold, or changed between unrecorded times. Similarly, the graph's branching is **not proof that an organism split**. This is a coarse sampled graph of numerical occupancy, not an independently tracked biological lineage.

## Verified pilot observations

The retained [G0034 numerical analysis](https://github.com/interrupt21h/ontogenesis/releases/download/atlas-media/g0034-genealogy.json) documents the following endpoint counts of periodic four-dimensional exclusive-region components:

| Original seed | Treatment | V-only components at step 240 | W-only components at step 240 |
|:--|:--|--:|--:|
| 42 | Near transition, no niche | 1 | 0 |
| 42 | Complementary niche 0.70 | 0 | 1 |
| 73 | Near transition, no niche | 0 | 1 |
| 73 | Complementary niche 0.70 | 1 | 1 |

The complementary-niche treatment preserves both kinds of exclusive region at the endpoint for seed 73, **but not seed 42**. This is not a claim of indefinite coexistence. It illustrates why both the time history and the seed-to-seed comparison matter, instead of selectively rendering the aesthetically strongest case.

The full JSON contains all observed component counts, largest-region sizes, threshold entries/exits, sampled split/merge counts, displayed component sizes and exact overlap edges.

## Art-directed companion: Luminous Habitat

The same numerical field archives also support a **separate artistic edition**, [Luminous Habitat](https://github.com/interrupt21h/ontogenesis/releases/download/atlas-media/ontogenesis-0034-luminous-habitat.mp4), whose creative goal is to evoke an unfamiliar, bioluminescent computational habitat rather than draw a graph. The actual stored seed-73 4D field is viewed one recorded omega hyperplane at a time. Luminous geometry derives from real exclusive V/W active sites and real face-adjacent pairs within each 3D hyperplane; matrix material derives from the archived numerical channel.

The triptych contrasts the prescribed niche-strength-0.70 arm with the matched no-niche arm. Light scattering, optical bloom, film camera orbit and editorial scene changes are clearly disclosed as presentation—not new physics, agent behaviors, or inferred life. The 24-second film was verified by [CI run 45461974208](https://github.com/interrupt21h/ontogenesis/actions/runs/45461974208), with 576 decoded 1280×720 frames and a published [poster](https://github.com/interrupt21h/ontogenesis/releases/download/atlas-media/ontogenesis-0034-luminous-habitat.png), [render manifest](https://github.com/interrupt21h/ontogenesis/releases/download/atlas-media/ontogenesis-0034-luminous-habitat.render.json), [renderer](../../g0034_luminous_habitat.py) and [spatial-filament geometry tests](../../tests/test_g0034_luminous_habitat.py).

These two G0034 editions deliberately have different jobs: **Lineage Ribbons** exposes sampled connectivity and overlap, while **Luminous Habitat** creates a cinematic encounter with the recorded field itself. The shared standard is the [Ontogenesis artistic rendering charter](../ART_DIRECTION.md).
